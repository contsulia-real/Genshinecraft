# Genshinecraft

将《原神》的元素战斗机制融入 Minecraft 的模组项目。

当前为**开发骨架**：已准备跨版本 / 跨加载器 Gradle 工程与最小模组入口，下面的玩法规则是**已确定的设计**，还没有实现成可玩的内容。

## 支持的构建目标

| Minecraft | Fabric | Forge | NeoForge | JDK |
|---|---|---|---|---|
| 1.20.1 | ✓ | ✓ | — | 17 |
| 1.21.1 | ✓ | — | ✓ | 21 |
| 26.3 | ✓ | — | ✓ | 25 |

Gradle 9.7.1 + Stonecutter 0.9.7 + Architectury Loom。全局 Gradle 依赖缓存可复用，禁止 Gradle 自动下载 JDK。

在项目根目录，按需构建单个目标：

```powershell
.\gradlew.bat :fabric:1.21.1:build --offline --no-daemon
.\gradlew.bat :forge:1.20.1:build --offline --no-daemon
.\gradlew.bat :neoforge:26.3:build --offline --no-daemon
```

Linux/macOS 使用 `./gradlew`；去掉 `--offline` 才会按需解析尚未缓存的依赖。全部六个目标可用 `chiseledBuild` 构建，但默认不执行全部目标。

JAR 位于 `<加载器>/versions/<Minecraft 版本>/build/libs/`。Fabric 还需要 Fabric API，三个加载器均依赖 Architectury API。

## 已确定的玩法规则（尚未实现）

### 元素载体

- 神之眼、月之轮、星之楔均是有固定元素属性的独立物品，每件载体的元素不能改变。
- 元素战技和元素爆发是否开发**尚未决定**，当前不列入开发目标。载体数据中预留的相关字段不代表已确定会实装。
- 元素精通是这三类载体的**专属附魔**。
- 玩家首次持有的载体认主，所有权不可转移；主人可以主动放弃。载体默认死亡不掉落。
- 玩家背包和兼容饰品 Mod 的装备槽中的载体均可生效；不持有载体时，不能通过它使用元素力。
- 使用元素力不需要武器；是否提供空手释放元素战技、元素爆发的玩法，待技能系统开发决策确定后再讨论。

### 武器与元素反应

- 将元素载体拖放至武器，可将武器和该载体绑定，载体仍保留为独立物品。
- 该武器的普通攻击附加对应元素伤害与附着；若载体不在玩家身上，武器不能通过该载体释放元素效果。
- 携带月之轮时，对应常规反应自动转换为月曜反应；携带星之楔时，对应反应自动转换为星烁反应。
- 一次触发只结算转换后的反应，不同时结算原始反应。

### 神像、共鸣与供奉

- 神像是世界生成结构，不是单独一个神像方块；元素载体通过共鸣获得，**每座神像全服务器只有一次共鸣机会**。
- 共鸣成功率为 **80%**；无论成功或失败，该神像都永久不能再次共鸣。
- 某些神像要求先完成挑战才能尝试共鸣。
- 成功共鸣获得的载体关联其来源神像。
- 元素之印可从各类结构战利品宝箱获得，也可挖掘对应元素矿石获得；七种元素矿石每次掉落对应元素之印 **1～3** 枚，**时运不影响数量**。非岩元素矿石另有 **5%** 概率额外掉落 **1 枚岩之印**，同样不受时运影响。
- 向七天神像供奉对应的元素之印提高等级；同源载体增加元素精通。每成功升至等级 `N` 发放 `5 + 2*(N-1)` 点经验值，每到 10 的倍数等级再奖励 3 枚月之印。
- 神像供奉界面保留双栏布局并采用原版 Minecraft 容器边框：左侧上下占满的窗口使用**真实方块模型与原始贴图的三维相机预览**（读取当前神像结构并随世界变化更新）；右侧采用交易列表外观，逐级展示对应元素之印的图标、实际数量与元素精通，使用村民交易原版经验条显示供奉进度。`升一级`、`供奉全部`两个按钮位于右栏底部，不展示玩家背包栏位；背包对应的具体“风之印／岩之印／水之印”等自动统计。「升一级」仅在印数足够时扣除并升一级，「供奉全部」消耗所有对应印，可连升多级并保存余量。
- 各神像初始等级 1，初始开放 50 级；达到 50 级后每次升级开放下一等级，没有设计上的最终封顶。升级到目标等级 `N` 消耗 `4 + floor(N/3) + floor(N²/250)` 枚对应元素之印，允许多次投入。等级 `L` 提供的元素精通为 `2(L-1) + floor((L-1)/5)`。
- 各神像等级、已供奉数量在世界保存并由服务器所有玩家共享。持有源自该神像的神之眼、月之轮或星之楔获得该精通成长。
- 月神像为单独生成的世界结构，不提供共鸣，只消耗月之印。**同一玩家所有月神像共享一份供奉等级和进度，不同玩家按 UUID 独立保存**，该玩家拥有的每一枚有效外置魔力器官都获得全额月神像元素精通加成，不分摊。每升一级获得经验值和 1 颗绿宝石，每到 5 级额外 3 颗；月神像不会奖励月之印。旧的按神像坐标保存的月神像记录不自动迁入新玩家记录。

## 工程结构

- `src/main/java/dev/genshinecraft/`：跨加载器公共代码与初始化。
- `fabric/`、`forge/`、`neoforge/`：各加载器入口与专用资源。
- `versions/`：各 Minecraft 版本的依赖和 JDK 配置。
- `build.gradle.kts` 与 `build.26.gradle.kts`：旧版和 26.3 的公共构建脚本。

尚未实装：物品注册、神像生成与共鸣、元素能力、技能与伤害计算、饰品兼容、数据持久化。具体数值与未决定的规则不预设。

## 许可与素材

项目基于 [MIT 许可证](LICENSE)。这是非官方同人模组；不包含《原神》的美术、音效或其他游戏资源。
- 传送：在设置→控制里可以修改「神像传送」键（默认 V）。手持已认主且来源有效的外置魔力器官按键，服务器验证后传送到获得它的七天神像；手持月之印则传送到当前维度最近的已登记月神像。两者均要求安全落脚点，并在物品 tooltip 明示按键。
